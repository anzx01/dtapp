# Pencil 插件输入稿：定投计划设置向导

## 设计目标

请根据 `D:\aiapp\dtapp\定投计划设置向导_PRD.md` 设计一套移动端可点击原型。产品是普通用户的定投计划设置与执行工具，核心目标是让用户在 3 分钟内创建一份可执行、可提醒、可记录、可复盘的定投计划。

## 设计原则

- 规则先行：先设置目标、预算、买入/卖出规则，再进入执行。
- 默认简单：默认项可直接继续，高级配置折叠。
- 长期导向：强调低估多投、高估少投、长期持有。
- 减少情绪干扰：避免行情刺激型界面，不做交易撮合。
- 可记录可复盘：计划详情页必须提供记录和复盘入口。

## 页面范围

1. 新手引导页：标题“只需几步，创建你的定投计划”，副标题“先设规则，再开始执行”，含开始、查看示例、跳过。
2. 目标设置页：目标类型为长期增值、养老准备、教育金、财务自由、其他；期限为 3 年以内、3-5 年、5 年以上、未确定。
3. 月度预算页：每月定投金额、每月可支配结余、备用金开关、未来 3 年大额支出开关、风险提示。
4. 品种选择页：宽基指数、策略加权指数、优秀行业指数、推荐组合；默认推荐宽基指数。
5. 买入规则页：固定金额、定期不定额、估值定投、自定义；展示低估/正常/高估的投入比例。
6. 频率与时间页：每周/每月；发工资后第一个交易日/自定义日期；展示下次执行时间。
7. 卖出规则页：收益率止盈、估值止盈、长期持有；触发阈值、分批比例、卖出后资金去向。
8. 提醒与记录页：定投提醒、估值提醒、月度复盘提醒；记录字段包括日期、品种、买/卖、金额、估值、备注。
9. 计划确认页：汇总目标、预算、品种、买入规则、频率、卖出规则、提醒设置；主按钮“创建计划”。
10. 计划详情页：当前目标、预算、品种、估值状态、下次执行时间、当前建议动作、计划状态；入口包括立即执行、修改计划、查看记录、查看复盘建议。
11. 定投记录页：记录本次执行结果，保存后回到详情页。
12. 复盘优化页：月度/季度复盘清单，保存复盘记录。

## 视觉方向

可点击原型优先保证流程、状态和交互闭环，同时保持清晰信息层级。使用克制、安静、工作流导向的金融工具风格；不要营销落地页，不要收益承诺，不要复杂图表。主色建议使用沉稳绿色，辅助色使用纸色背景和细线分隔。

## 交付要求

- 画布上展示完整流程，使用箭头连接页面。
- 每个页面使用 375x812 移动端尺寸。
- 每页标注页面标题和关键操作按钮。
- 所有主按钮、返回、跳过、保存、返回修改入口均可点击。
- 主路径必须可跑通：新手引导 → 目标 → 预算 → 品种 → 买入规则 → 频率时间 → 卖出规则 → 提醒记录 → 计划确认 → 计划详情。
- 执行路径必须可跑通：计划详情 → 记录定投 → 保存成功 → 返回计划详情。
- 复盘路径必须可跑通：计划详情 → 复盘优化 → 保存成功 → 返回计划详情。
- 修改路径必须可跑通：计划详情 → 修改计划 → 二次确认 → 返回向导对应步骤。
- 异常路径需要展示：未选品种不能继续、预算过高展示风险提示、估值状态未知时展示保守提示。
- 输出可继续编辑的 Pencil 设计文件，并导出 SVG/PNG 预览。
